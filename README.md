# Git Commands – Complete Learning Guide

Welcome to the **Git Commands** repository!

This repository is a structured, day-by-day learning guide to Git and GitHub. It covers essential Git commands with simple explanations, syntax, practical terminal examples, and real-world use cases.

The goal is to develop strong practical knowledge of version control and understand how Git is used in software development.

## 📚 Topics Covered

### 1. Git Basics
- Introduction to Git and Version Control
- Git Installation and Configuration
- `git --version`
- `git init`
- `git clone`
- `git status`

### 2. File Management
- `git add`
- `git add .`
- `git add -A`
- `git rm`
- `git mv`

### 3. Commit Management
- `git commit`
- `git commit --amend`
- `git log`
- `git log --oneline`
- `git show`

### 4. Branch Management
- `git branch`
- `git checkout`
- `git switch`
- `git merge`
- `git branch -d`

### 5. Remote Repository Operations
- `git remote`
- `git fetch`
- `git pull`
- `git push`

### 6. Comparing Changes
- `git diff`
- `git diff --cached`
- `git diff HEAD`
- `git diff --stat`

### 7. Undo and Recovery Operations
- `git reset --soft`
- `git reset --mixed`
- `git reset --hard`
- `git revert`
- `git restore`
- `git reflog`

### 8. Advanced Git Commands
- `git stash`
- `git rebase`
- `git cherry-pick`
- `git tag`
- `git bisect`
- `git blame`
- `git clean`

## 🎯 Learning Objectives

- Understand Git fundamentals and version control concepts.
- Learn to manage source code changes effectively.
- Understand staging, commits, and repository history.
- Work with branches and merging.
- Manage local and remote repositories.
- Identify differences between Git commands.
- Safely undo changes and recover previous commits.
- Gain practical experience through terminal demonstrations.

## 💻 Practical Learning

Each command is explained using:

1. **Definition** – What the command does.
2. **Syntax** – How to use the command.
3. **Example** – Practical terminal demonstration.
4. **Use Case** – Where and why developers use it.
5. **Best Practices** – Important points to remember.

## 🛠️ Requirements

- Git
- Linux Terminal / Ubuntu
- GitHub Account
- Basic command-line knowledge

## 📖 Intended Audience

- Beginners learning Git and GitHub.
- Software developers.
- Embedded Software Engineers.
- Linux and Android developers.
- Anyone interested in version control.

Build practical Git and GitHub knowledge through structured learning, hands-on demonstrations, and real-world software development examples.
